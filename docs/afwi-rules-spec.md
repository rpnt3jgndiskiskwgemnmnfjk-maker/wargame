## 3. ボード

[一次][ファン：ボード画像で確認]

```
      ┌──────────── PRC 側 ────────────┐
      │  PRC Airbase        │ PRC Standoff │   ← PRC の基地エリア
      ├────────────────────────────────┤
      │ PRC 1 帯 ＝ US 5 帯              │
      │ PRC 2 帯 ＝ US 4 帯              │
      │ PRC 3 帯 ＝ US 3 帯  （中央）      │   ← 距離帯（Range Band）5本
      │ PRC 4 帯 ＝ US 2 帯              │
      │ PRC 5 帯 ＝ US 1 帯              │
      ├────────────────────────────────┤
      │ US Standoff │ US Airbase │ US Contingency Location │ ← US の基地エリア
      └──────────── US 側 ────────────┘
      ＋ 各陣営に Cyber Track（0〜4）と Intel Track（Normal / Advantage）
```

- **距離帯（Range Band）**：5本。各陣営は自陣側から 1〜5 と番号を振る。ある帯は、US 側から見て n 帯、PRC 側から見て 6−n 帯になる。
- **Airbase（基地）**：飛行隊カードを伏せて置く場所。被攻撃時の損害ブロックが3つ追加で付いている（後述）。
- **Contingency Location（CL、US のみ）**：ACE を表す分散拠点。地理的に離れているため、攻撃の損害が及ぶ範囲が限られる。その代わり出撃時に D4 判定がある。
- **Standoff（スタンドオフ）**：各陣営に1つ。AEW 機と爆撃機（Standoff 表記あり）を置ける。
- **距離の数え方 [推定]**：自陣の基地エリア（Airbase、CL、Standoff）を位置0、自陣 1〜5 帯を位置1〜5、敵基地エリアを位置6とし、距離 = 位置の差の絶対値。根拠は次の2点で、どちらとも矛盾しない。
  - S1 の記述「B-52 は射程6で、Standoff から敵基地を撃てる」
  - S6 の要約「5帯に加え、両端に6番目（Airbase、Standoff、CL）がある」

## 5. ゲームの流れ（全体）

```
キャンペーン準備
 └─ ATO サイクル × N（N はキャンペーンで決まる）
      ├─ ATO 準備：態勢 → 飛行隊の選択・配置 → イネーブラーの選択
      ├─ 主導権の入札（Bid for Initiative）
      ├─ 情報判定（Play Intel）
      ├─ ターン（両者交互。両者が続けてパスするまで）
      └─ 終了・後片付け・VP 計上
ゲーム終了：ミッションカードを公開して VP を合計。最多 VP のプレイヤーが勝ち
※ 例外：サイバーレート 4 に到達したら、その時点で即勝利
```

### 5.1 キャンペーン準備 [一次]

1. 2チームに分かれ、US と PRC を決める。
2. キャンペーン（§10）を合意で1つ選び、そのキャンペーンで禁止されたカードを除く。
3. キャンペーンが指定していればミッションと態勢を割り当てる。
4. 指定がなければ、各自ミッションカードを1枚選び、**伏せて保持**する。
5. Cyber Track のマーカーを **1** に置く。
6. Intel Track のマーカーを **Normal** に置く。

### 5.2 ATO 準備 [一次]

1. **態勢を選ぶ**（キャンペーンで指定されていなければ）。選んだカードは表向きにする。
   - **同じ態勢は2回使えない**。ただし Standard は何度でも選べる。
2. **飛行隊を選ぶ**。まだ使えるカードの中から、態勢カードの上限枚数まで。
3. 飛行隊カードを **Airbase か CL に伏せて**置く（CL は US のみ）。
4. 各飛行隊に対応する航空機または ADA のトークンを、そのカードの上に**伏せて**載せる。
5. **イネーブラーを選ぶ**。まだ使えるカードの中から、態勢カードの上限枚数まで選び、相手に見せずに手元に置く。

> 手順の順番について：S2 のスライドは「イネーブラー → 飛行隊」の順で説明している。S1 は「飛行隊 → イネーブラー」の順。どちらも準備段階の中の話なので、結果は変わらない **[推定]**。

### 5.3 主導権の入札（Bid for Initiative）[一次]

1. 各自、準備で選んだイネーブラーの中から**入札に差し出す枚数**を決める。1枚につき出目に +1。
2. 差し出したカードは**それぞれのデッキに戻る**。この ATO では使えなくなるが、失われるわけではない。
3. 各自 D4 を1個振り、差し出した枚数を足す。
4. 同点なら、修正値はそのままで振り直す。
5. 勝者は次の3つを得る。
   - **先攻・後攻を選ぶ** **[確定]**（S1 の記述どおり。S3 のファン実装は「勝者が常に先攻」だが採用しない）
   - **サイバーレート上昇判定**を1回行う
   - **Intel Advantage** を得る（Intel Track をAdvantageへ。敗者は Normal に戻す：S2）

例（S2）：Red は 出目2＋入札3＝5、Blue は 出目3＋入札1＝4 で Red の勝ち。Red はサイバーを 1→2 に上げ、どちらが先攻かを決める。

### 5.4 情報判定（Play Intel）[一次]

- 各自 D4 を1個振る。出目の枚数だけ、**相手が選んだイネーブラーを見られる**。
- Intel Advantage を持つ側は、この判定を**有利**（§6.1）で振る。

### 5.5 ターン [一次]

手番のプレイヤーは、次の **(A) と (B) のどちらか、または両方を好きな順で**行う。どちらもしなければパスになる。

- **(A) 次のどちらか1つ**
  - 飛行隊カード1枚を**起動**する（§7.1）
  - **Move-Acquire-Shoot（MAS）行動**を1回行う（§7.2〜7.4）
- **(B)** イネーブラーを1枚使う

MAS 行動の制約：
- 「移動1回、捕捉1回、射撃1回」を**それぞれ最大1回**ずつ行える。
- 順番は自由（射撃 → 移動 → 捕捉でもよい）。
- 3つを**別々のトークン**で行ってもよい。
- どれを省略してもよい。

### 5.6 ATO 終了・後片付け [一次]

1. **両者が続けてパス**したら ATO が終わる。
2. 使った Single Use イネーブラーはゲームから除く。
3. 盤上のトークンとカードをすべて取り除く。Airbase、CL、Standoff の上にあるものも含む。**Cyber Track と Intel Track のマーカーはそのまま残す**。
4. その ATO で得た VP を計上する。
5. 次の ATO で使えるカードとトークンを整理する。
6. キャンペーンの規定 ATO 数に達していなければ、次の ATO を始める。

> ATO の終わりに、上空にいる航空機はすべて自分の飛行隊カードへ帰投する。**撃破済みの飛行隊カードに帰投した機体は撃破扱い**になる [一次]。
> ATO をまたいで損害が持ち越されるかどうか（撃破された飛行隊やトークンを次の ATO で使えるか）は、S1 の「使用可能なものを整理」という記述と、撃破物を「撃破した側が保管」するというルールから、**使えなくなると解釈**した [推定]。S3 も「persistent attrition（損耗の持ち越し）」として実装している [ファン]。

## 6. ダイスの判定

### 6.1 基本と有利・不利 [一次]

- 判定は D4 を1個振り、**閾値以上なら成功**。表記は「n+」。
- **有利（Advantage）**：2個振って高い方を採る。
- **不利（Disadvantage）**：2個振って低い方を採る。
- 有利と不利が両方かかると**相殺**され、通常どおり1個振る。
- 有利・不利は**重ならない**（有利が2つあっても有利は1つ分）。
- ボーナス修正（例：AEW の +2）は出目に足す。

### 6.2 成功確率（参考、本書で計算）

| 閾値 | 通常 | 有利 | 不利 |
|---|---|---|---|
| 2+ | 75.0% | 93.75% | 56.25% |
| 3+ | 50.0% | 75.0% | 25.0% |
| 4+ | 25.0% | 43.75% | 6.25% |

- 計算式：通常 p＝(5−t)/4、有利 1−(1−p)²、不利 p²。
- AEW の +2 ボーナスがあると、2+ と 3+ は必ず成功し、4+ は 75% になる。

## 7. 行動の詳細

### 7.1 飛行隊の起動（Activate）[一次]

- ATO の開始時点では、飛行隊カードはすべて未起動。
- 起動すると、カードを表向きにし、対応するトークンを**伏せたまま**盤上に生成する。

| 機種 | 生成先 |
|---|---|
| 戦闘機 | 自陣 1 帯 |
| UAS（無人機） | **任意の帯** |
| AEW、爆撃機（Standoff 表記あり） | 自陣 1 帯 または 自陣 Standoff |
| ADA（防空） | その飛行隊がいる Airbase |

- **CL から起動する場合**：D4 を振り、**出目の数だけ**機体が生成される（上限は飛行隊の機数）。生成できなかった機体は、その ATO 中は使えない。
  - 例外：**ACE 態勢**のとき、または **Flying Crew Chief** イネーブラーを使ったときは、判定なしで全機生成する。

### 7.2 移動（Move）[一次]

- MAS の中で、トークン1個を**移動力の数まで**帯を前後に動かせる。
- 移動力：戦闘機は2、爆撃機・AEW・UAS は1、ADA は0 [ファン]。
- 次のものは移動に数えない。
  - イネーブラーによる配置
  - 盤上からの除去
  - 弾切れ（Winchester）による帰投

### 7.3 捕捉（Acquire）[一次]

- トークンはすべて**未捕捉（伏せた状態）**で盤上に入る。
- MAS の中で、トークン1個から捕捉を試みる。対象は**捕捉射程内**（前後どちらでも可）の敵トークン。
- 必要な出目は**対象トークンの裏面**に書かれている（例：2+）。本プロジェクトで採用する機種ごとの値は §11.1 **[確定]**。
- 成功すると対象を**表向き**にする。以後その ATO 中は、**全プレイヤー・全ユニット**から見える状態になる。
- AEW は捕捉判定を**2回**行え（×2）、各判定に **+2** が付く。2回を同じ目標に使っても、別の目標に使ってもよい。
- イネーブラーでも捕捉できる（例：「D4 を振り、出目の数だけ捕捉」「サイバーレートの数だけ捕捉」）。
- **原則として、捕捉していない目標には攻撃できない**。ただし **Airbase と CL にいるものは捕捉なしで攻撃できる**。

### 7.4 射撃（Shoot）[一次]

- MAS の中で、トークン1個から射撃する。イネーブラーによる射撃もある。
- 射撃の種類：
  - **対空（ミサイルのアイコン）**：航空目標を撃つ
  - **対地・対水上（爆弾のアイコン）**：地上・水上の目標と基地を撃つ
- アイコンの下の数値が**最大射程**、ダイスのアイコン内の数値が**命中に必要な出目**。
- **損害**：
  - 通常のダイスのアイコン：1回の射撃で最大1点。
  - **爆発ダイス（ダイスに光芒）**：命中したら、もう一度 D4 を振り、**その出目の点数だけ損害**を与える。
- **耐久力**：
  - トークンは**1点で撃破**。
  - 飛行隊カードは**2点で撃破**。
  - 海上の水上戦闘艦について：S3 のファン実装は「3点耐久」としている。S1 では確認できなかった **[未確認]**。
- **基地への損害の割り振り**：
  - 爆発ダイスで Airbase を攻撃した場合、相殺されなかった損害を、**攻撃側が**基地内に自由に割り振る。
  - 基地には**追加の損害ブロックが3つ**あり、ここを狙うと VP を得られる（基地内のユニットには影響しない）。このブロックの VP 値は S1 では確認できなかった **[未確認]**。
  - **CL** を攻撃した場合、1回の攻撃で損害を与えられるのは**飛行隊カード1枚とその所属機だけ**。
- 地上にいる飛行隊カード（生成前の機体や帰投した機体が載っている状態）を撃破すると、**載っているトークンも全部撃破**される。
- 撃破したトークンやカードは**撃破した側が保管**する（VP 計上用）。
- 「回復」したトークンやカードは元の持ち主に戻り、VP 計上には数えない。

### 7.5 弾切れ（Winchester）[一次]

| 対象 | Winchester になる条件 |
|---|---|
| 航空機（通常） | 射撃の出目が **4 未満**（命中したかどうかに関係なく）。4 は「全弾を使わずに当てた」ことを表す |
| ADA | Winchester にならない |
| 攻撃型 UAS（∞の印） | 出目が **1 か 2** のとき |
| 艦艇 | 灰色の**斉射ブロック**の数が弾数。射撃するたびにブロックへキューブを置き、出目4ならブロックを消費しない。全ブロックが埋まると Winchester |

- Winchester になったトークンにはキューブを置く。
- **自分の手番の開始時**に、Winchester の航空機は自分の飛行隊カードへ帰投する。艦艇は盤外へ出る。どちらも無料移動で、移動に数えない。

### 7.6 ミサイル防衛（Missile Defense）[一次]

- **ミサイル防衛ができるトークン**：盤上に生成された ADA と、MD 表示（盾と爆弾のアイコン）のある艦艇。そのトークンの交戦域（WEZ、ミサイルのアイコン下の射程）を**攻撃が横切る**とき、防衛側はミサイル防衛を宣言できる。
- **宣言のタイミング**：攻撃の宣言直後。命中判定・損害判定・付随するイネーブラーの使用より**前**でなければならない（命中を見てから使うことはできない）。
- **艦艇の場合**：空対空の斉射ブロックが残っている必要がある。宣言時にそのブロック1つにキューブを置く。
- **効果**：攻撃側は **命中判定も損害判定も不利**で振る。
- **地上の ADA**：自分の WEZ 内にある地上・水上目標への敵の射撃と損害判定を、**常に**不利にする。
- **例外**：「Unblockable」と書かれたイネーブラーと、PRC の SOF 直接行動カード2枚（蛟龍突撃隊攻撃、海軍陸戦隊突襲）にはミサイル防衛が効かない。ただしミサイル防衛以外の手段では軽減できる。
- **「WEZ を横切る」の判定法 [推定]**：§3 の位置座標で、射撃元から目標までの区間 [min, max] と、防衛トークンの WEZ 区間 [位置−射程, 位置＋射程] が重なれば、横切るとみなす。

### 7.7 サイバートラック [一次]

- 値の範囲は 0（能力なし）〜 4（完全な優勢）。初期値は 1。
- 上げる機会：主導権入札に勝ったとき、一部のイネーブラーを使ったとき。
- 上げる判定 **[確定]**：D4 で **現在値＋1 以上**を出すと1段上がる（言い換えると、サイバー値は「必要な出目−1」）。

  | 現在値 → 次の値 | 必要な出目 | 成功確率 |
  |---|---|---|
  | 0 → 1 | 1+ | 100% |
  | 1 → 2 | 2+ | 75% |
  | 2 → 3 | 3+ | 50% |
  | 3 → 4 | 4+ | 25% |

  S1 本文には数値がなく、S3 のファン実装と同じ方式を採用した。
- **サイバーレートが 4 に達した側は、その時点で勝利**する。
- サイバー系イネーブラーの効果量（捕捉数、除去数など）はサイバーレートに比例する。
